# Calculadora em C

## Descrição e objetivo
Calculadora de linha de comando que lê dois números e um operador
(+, -, *, /) e mostra o resultado. Desenvolvida para praticar
funções, separação entre entrada, cálculo e saída, e tratamento de erros
(divisão por zero e operação inválida).

## Linguagem e tecnologias
- Linguagem C
- Compilador GCC
- Desenvolvido no Code::Blocks

## Como executar
1. Compile:
   `gcc main.c -o calculadora`
2. Execute:
   `./calculadora` (no Windows: `calculadora.exe`)
3. Digite o primeiro número, o segundo e o operador quando solicitado.

## Exemplo
```
Primeiro numero: 10
Segundo numero: 4
Operacao (+ - * /): /
Resultado: 2.50
```
